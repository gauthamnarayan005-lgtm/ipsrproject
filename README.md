# ipsrproject - Book Tracker

A clean, responsive, and lightweight Book Tracker web application to log, organize, and track your reading journey.

## Features
- **Add Books**: Record book title, author, and reading status (To read, Reading, Finished).
- **Status Management**: Quickly update the status of any book directly from the list.
- **Search & Filter**: Real-time search across your book collection.
- **Reading Statistics**: Live counters for total books, currently reading, and finished books.
- **Persistent Storage**: Saves data in `localStorage` so your reading list persists across sessions.
- **Responsive Design**: Clean UI optimized for mobile and desktop screens.

## Getting Started
Simply open `index.html` in any modern web browser or serve it with GitHub Pages.
